# Fonts

Bundled so the game renders correctly offline. Both are licensed under the SIL Open Font License 1.1
(https://openfontlicense.org), which allows embedding and redistribution with the game.

| File | Family | Source | Used by |
|---|---|---|---|
| `baloo2.woff2` | Baloo 2 (600–800, latin subset) | Google Fonts, Ek Type | UI font, most themes |
| `pressstart2p.woff2` | Press Start 2P (latin subset) | Google Fonts, CodeMan38 | Rétro and Arcade themes |

Add any new font file to `ASSETS` in `sw.js`.
