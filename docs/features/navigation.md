# Navigation (tab bar, home, dialogs)
Status: shipped (2026-09-30, UI/UX audit)

## What it does
- **Full-screen menus**: the app is phone only. The hubs and menu screens (Jouer, Défis, Boutique, Profil, Aventure, Puzzles, Paramètres, Album) fill the screen (`src/ui/Screen.tsx`, safe-area aware), the tab bar docks to the bottom edge. Dialogs and sheets (`ask`, the Partie libre sheet, level sheet, results, pause) are native Modals or bottom sheets (`src/ui/Sheet.tsx`). The web build's wide-screen layout (menu cards floating over the theme's decor, `menuBackground`) has no counterpart: menus are plain theme colors.
- **Menu theme**: menu screens, sheets and the tab bar always wear the equipped theme (`src/theme/useColors.ts` + `src/theme/menu-themes.ts`); the game and its in-game cards wear the theme played.
- **Coins**: tapping the coin count (HUD wallet, Jouer and Défis headers) opens the Boutique tab (`goShop` in `src/screens/GameScreen.tsx` saves the run first; the headers use `src/ui/Counter.tsx`). A run in progress waits behind, as with any menu. The legacy "not during the tutorial" rule was not checked in the port.
- **Swipe**: no swipe between tabs (user choice): tabs change from the tab bar only (React Navigation's bottom tabs). A swipe remains on the Aventure world page (next / previous world, `Gesture.Pan` in `src/screens/AdventureScreen.tsx`). The Défis calendar has arrows only (`src/screens/defis/Calendar.tsx`); the legacy calendar swipe is not ported.
- **Parked free run**: starting a level, a daily or a puzzle during a free run (Classique, Chrono, Chill, Mondes) parks it in `parked` instead of ending it (`src/game/run.ts`). The Partie libre row (`src/screens/PlayScreen.tsx`) then shows it with Reprendre (`resumeParked`). Starting a new free run (sheet or endless world) asks (`guardFree` in `src/game/modes.ts`), then settles the parked run's coins and missions (`dropParked`).
- **Button labels** stay on one line: `adjustsFontSizeToFit` on `Text` (see `src/ui/Button.tsx`, `src/ui/Text.tsx`) shrinks a label that doesn't fit. Disabled buttons come from `Button`'s `disabled` state.
- **Tab bar** (`src/navigation/RootNavigator.tsx`, bottom tabs, safe-area aware): Jouer, Défis, Boutique, Profil. These four are the hub screens; the game, Adventure, Event, Puzzles, Album and Settings are stack routes above them (`src/navigation/types.ts`), so the bar is hidden there. A red dot on Défis while today's level can still be won (`DefisIcon`, `defisDot` in `src/game/daily.ts`).
- **Jouer** (`src/screens/PlayScreen.tsx`): header (brand, coins, settings gear), Continuer for any run in progress (free run, Aventure level, daily, event level, puzzle; label and progress from `resumeOf` in `src/game/home.ts`; the Aventure card turns secondary while it shows), the Aventure hero card (next level to play with its world preview; tap = Aventure page on that level's world (user's choice 2026-10-01, not the level sheet), "Carte" chip = same page), one big row per open event (next level, cleared count, end date), tiles Défi du jour (opens the Défis tab, where a daily in progress resumes) and Puzzles (a puzzle in progress resumes from it), the Partie libre row (last mode and level; the chevron opens the Partie libre sheet, `src/ui/FreePickSheet.tsx`, to change them, Jouer starts), and a Missions row that jumps to the Défis tab.
- **Défis** (`src/screens/DefisScreen.tsx`): today's level card with a Play button, streak card + freeze, today's missions, then "Rattraper un niveau manqué" which unfolds the calendar.
- **Boutique** (`src/screens/ShopScreen.tsx`): Thèmes, Blocs, Cubo, Bonus (upgrades). World themes say "Ou bats son boss". Only reachable from the tab bar (the in-game wallet is display only).
- **Profil** (`src/screens/ProfileScreen.tsx`): totals, Album row (own screen), trophies, Stats, and a gear button on the header's right that opens the Settings screen.
- **Aventure** (one screen, `src/screens/AdventureScreen.tsx`): strip of world thumbnails on top (scrolls sideways), the picked world below (rules, chests, levels path, endless run). Swipe the world page or use its arrows to change world; a locked world shows what opens it. The route params `{ world?, level? }` open it on a world; with none it opens on the world of the next level (`nextAdventure`). The separate world-map screen is gone.
- **Settings** (`src/screens/SettingsScreen.tsx`): titled Paramètres (was Réglages until 2026-10-07), opened from the Profil header's gear and from the pause (no gear on Jouer since 2026-10-01); grouped Sauvegarde en ligne (first: the cloud account, back from Profil on 2026-10-07 because players look for it here) / Son / Affichage / Langue / Aide; tapping a row flips its switch.
- **Dialogs**: `ask({ title, text, ok, danger })` (`src/ui/dialog.tsx`, a native Modal, promise based). `guardFree` (`src/game/modes.ts`) tells when to ask before dropping a run in progress.
- Close rules: stack screens have a back arrow (`src/ui/ScreenHeader.tsx`) that goes up one level (level sheet > world > map); the game's Menu goes back to the hubs.

**Android** (2026-10-06): the back button closes the sheet on top (`ui/Sheet.tsx`), opens the pause on the board (`GameScreen`; nothing during the tutorial or under a result card), pops stack screens and goes back to Jouer from the other tabs (React Navigation). The button bar has no contrast scrim (`expo-navigation-bar` plugin, `enforceContrast: false`); its buttons follow the menu theme (`App.tsx`) and it is hidden while the board is on screen (a swipe shows it). The status bar follows the played theme on the board. Stack screens scroll under the bar and end with its height (`ui/Screen.tsx`).

## Files
- `src/navigation/RootNavigator.tsx`, `src/navigation/types.ts`: tab bar and stack routes.
- `src/ui/dialog.tsx` (`ask`), `src/ui/Screen.tsx`, `src/ui/ScreenHeader.tsx`, `src/ui/Sheet.tsx`, `src/screens/PlayScreen.tsx` (Jouer), `src/screens/DefisScreen.tsx`.

## Saved state
`cuboblocks.v2` gained `parked` (a run state, optional, no migration; `src/state/persist.ts`). `profile.adventure.fails` (see aventure.md) drives the paid skip on the level sheet.

## Gotchas
- The web build's tab bar hacks (`syncTabbar` observer, `.no-anim`, fixed hub card heights, `.card.sticky-foot`) do not exist: React Navigation owns the tabs and the end cards (`src/screens/GameOver.tsx`, `src/screens/LevelEnd.tsx`) scroll inside a `ScrollView`.
