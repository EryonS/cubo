# RN port, milestone 1: Foundations Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** An Expo SDK 57 app at the repo root, with the pure core ported to TypeScript (all 15 test files passing), FR / EN i18n, MMKV + zustand state, design tokens and fonts, and a 4-tab shell showing live core data, running on the iOS simulator and the Android emulator.

**Architecture:** The Capacitor game moves to `legacy/` untouched. `src/core/*.ts` are line-for-line ES-module ports of `legacy/www/src/core/*.js`. The language is fixed before any core module evaluates (core tables call `tr()` at load), so a language change saves the choice and reloads the JS bundle. State lives in one zustand store persisted to MMKV through a small `KV` interface that tests replace with a `Map`.

**Tech Stack:** Expo SDK 57, React Native 0.86, React 19, TypeScript 6, React Navigation 7, react-native-mmkv, zustand, expo-font, expo-localization, expo-updates (reload), tsx --test.

**Spec:** `docs/superpowers/specs/2026-10-04-react-native-port-design.md`

## Global Constraints
- Identity: name `Cubo` (home screen), app `Cubo Blocks`, bundle id / package `com.slapps.cubo`, background `#ffeef4`.
- `src/core/` stays pure: no React, no React Native, no native module, no `Date.now()` outside what the legacy code already does, JSON-serializable state.
- Every player-facing string goes through `tr()`; French source text is the key; English in `src/i18n/en.ts`.
- No emoji anywhere. "forme" = shape, "pièce" = coin.
- Save keys: `cuboblocks.v2` (run), `cuboblocks.profile.v1` (profile), `cuboblocks.lang` (language pref).
- Install native deps with `npx expo install` so versions match SDK 57.
- `ios/` and `android/` are generated by `npx expo prebuild` and committed; never hand-edited.
- Scripts named as in Ressac: `ios`, `android`, `prebuild`, `xcode`, `check:types`, `check:unit`, `lint`.

## Review Focus
- **Language at load**: core tables translated with `tr()` at module load must come out in English on an English device. Test: `src/i18n/i18n.test.ts` sets `en` before importing `meta` and checks a table string.
- **Corrupt save**: a non-JSON value under `cuboblocks.v2` or `cuboblocks.profile.v1` must not crash start-up; it is kept under `<key>.broken` and a fresh state is used. Test in `src/state/persist.test.ts`.
- **Midnight rollover**: profile day rolls with `M.ensureDay` when the app comes back to the foreground. Test of `today()` formatting + `rollDay` pure helper in `src/state/persist.test.ts`.
- **Side-effect registration**: `worlds.ts` registers into `logic.ts` via `defineWorlds`; any app entry must import `src/core/index.ts`, never `logic.ts` alone. Test: `src/core/index.test.ts` checks a world rule is active after importing the index.
- **i18n coverage in TS**: the key scanner must read `.ts` / `.tsx` (template `tr\`\`` and `tr('')`), else missing translations pass silently. Test: `src/i18n/i18n.test.ts` "every tr() text has an English translation".

### Task 4: Port `logic`

**Files:** Create `src/core/logic.ts`, `src/core/types.ts`; tests `src/core/{logic-like legacy tests}.test.ts` for tests that only need logic.

Conversion rules (apply to every core module in Tasks 4-6):
1. Remove the UMD wrapper; `require('./x.js')` / `self.X` → `import * as X from './x'` (or named imports).
2. The returned object becomes named exports (`export { ... }` at the end, same names).
3. Annotate exported function parameters; shared shapes go to `src/core/types.ts` (`RunState`, `Cell`, `Shape`, `Piece`, `Inventory`, `Effects`, `Stage`, `Profile`, `Settings`). Internal helpers may rely on inference. No `any` in exported signatures; `unknown` + narrowing where the data is untyped JSON.
4. No behavior change: same constants, same RNG, same order of operations.
5. Tests: `legacy/tests/X.test.js` → `src/core/X.test.ts`, `require` → `import`, assertions unchanged.

- [ ] **Step 2:** Port the tests that import only logic (`upgrades.test.js` and the logic parts it needs). Run `npm run check:unit`. Expected PASS.
